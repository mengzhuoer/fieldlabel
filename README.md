# 耕图 FieldLabel · 遥感影像多类别标注工具

> 曾用名 **ParcelAnnotator**（源码目录 `parcel_annotator_v2`，v1 ~ v2.2.1）；自本版本起更名为 **FieldLabel（耕图）**，功能与数据格式完全兼容旧版——`parcels.geojson` / `label.npy` 契约保持不变。

一个**本地运行的网页式遥感标注工作站**：后端是一个零外部服务的 Python HTTP 服务（瓦片渲染 + 标签引擎），前端是完全离线的单页应用。双击即可用，标注结果直接落在影像旁边，可无缝接入你现有的 UNet / SegFormer / DeepLabV3+ 训练流程。

**核心能力一览**：网页选文件 · 多类别 · 多边形田块 · 涂抹/点划语义标注 · PS 同款选区（矩形/椭圆/套索/魔棒）· 文本标注 · 图像处理（亮度/对比度/饱和度/锐化/光平衡/拉伸/裁剪/旋转/翻转）· 多光谱转化（NDVI/NDWI/NDBI/自定义波段式）· 自动保存 · 统一撤销重做 · **多人实时协作（在线头像/远程光标/事件提示/增量合并/按人撤销）** · **抗锯齿圆刷与吸管** · 局域网多人共用。

## 零、一分钟快速开始

**目标电脑（免安装）**：
1. 解压 `FieldLabel_v1.0_portable.zip` 到任意目录（如 `D:\FieldLabel`）；
2. 双击 **`启动工具.bat`**——**首次运行会弹一次 UAC 授权窗口（Windows 防火墙放行），点"是"即可让局域网其他电脑访问**，之后不再弹；只想本机使用可直接取消；
3. 浏览器自动打开 `http://127.0.0.1:8765/` → 点左上角 **📂 打开文件** → 选影像 → 开始标；
4. 局域网协作：其他电脑访问 `http://本机IP:8765/`（IP 见启动窗口打印的日志）。

**开发机（源码）**：
```powershell
cd fieldlabel
pip install -r requirements.txt
python annotate.py D:\data\xxx.tif
```

页面里按 **`H`** 随时看快捷键速查。

## 一、功能总览

### 1.1 影像与文件
- **网页内文件浏览器**：盘符 → 目录 → 影像逐级浏览，双击进入/打开；支持直接粘贴路径回车跳转；最近访问目录自动记住（★ 标记）；「🏠 用户目录」一键回家。
- **格式**：任何 rasterio 能打开的栅格——GeoTIFF（int16/float32/uint8…）、IMG、VRT、JP2、PNG、JPG 等；多光谱（≥3 波段自动真彩色，6 波段 Sentinel2 全支持）与单波段均可。
- **大图流畅**：8350×6352 的影像通过 XYZ 瓦片流式渲染，平移缩放不卡；打开时做一次 2%–98% 百分位拉伸统计（约 1–3 秒），之后全部走缓存。

### 1.2 标注工具
| 工具 | 用法 | 说明 |
|---|---|---|
| ✎ 多边形（`P`） | 逐点单击，右键/回车/双击/点回起点闭合 | 顶点可拖动，边中点 ○ 可插点；自动编号 |
| 🖌 涂抹笔刷（`B`） | 按住左键涂抹；**单击 = 点一个圆点** | 直接写进标签图；尺寸 1–300px（`[` `]` / **`Alt+滚轮` 无级**）；**服务端抗锯齿圆刷**（超采样渲染，圆更圆、斜边更顺滑）；涂抹模式**右键弹出笔刷面板**（调大小、快速换类别）；光标旁实时显示 `尺寸 · 类别` |
| ⌫ 橡皮（`E`） | 按住左键擦除 | 只擦标签像素，绝不碰底图 |
| ▣ 选择（`V`） | 单击选中田块 → 拖顶点/整体移动 | 右侧面板可改选中田块的所属类别 |
| 📝 文本（`T`） | 点击画面输入文字，回车确认 | 拖动移动、双击编辑、Delete 删除；右侧有文本列表 |

### 1.3 PS 同款选区四件套
| 工具 | 快捷键 | 说明 |
|---|---|---|
| ▭ 矩形选框 | `R` | 拖拽画矩形，**Shift** 约束正方形 |
| ◯ 椭圆选框 | `O` | 拖拽画椭圆，**Shift** 约束正圆 |
| ∿ 自由套索 | `L` | 按住左键手绘，松手自动闭合 |
| ✦ 魔棒 | `W` | 单击一次，按**容差**自动选出颜色相似的连通区域（右侧滑杆 1–100 可调） |

- 选区显示 **PS 式动态蚂蚁线**，底部选区条实时显示 `像素数 · 面积(ha)`；
- 完成后两个去向：**「⇢ 转为田块」**（生成带当前类别的矢量）或 **「🖌 涂进当前类别」**（直接栅格化进标签图）；
- `Esc` / `Delete` 取消选区；魔棒结果过大时会提示「触到计算窗口上限」（partial 标记）。

### 1.4 多类别
- 默认 6 类：耕地 / 林地 / 草地 / 水体 / 建设用地 / 裸地·其他；
- 侧栏 **＋** 新增、**✎** 改名改色（ID 1–255）、**✕** 删除；**●** 按类别显示/隐藏叠加；
- `1`–`9` 快速切换当前类别；类列表上实时显示各类已涂像素（k=千）；
- 类别定义存 `annotator_config.json`，**跨影像、跨会话共用**。

### 1.5 🎛 图像处理面板（`I` 或工具栏按钮）
**A. 显示调整**（实时预览，只改观看不改数据，随会话记忆）
- 亮度 0.5–1.5 · 对比度 0.5–2 · 饱和度 0–2 · 锐化 0–2 · Gamma 0.5–2
- **光平衡**：灰度世界法白平衡，一键校正整幅影像色偏
- **拉伸范围**：百分位线性拉伸（默认 2%–98%，可改 0–100）
- 「↺ 重置显示调整」一键还原

**B. 多光谱转化**
- 波段组合下拉：真彩色 / 假彩色(NIR) / NDVI / **NDWI** / **NDBI** / **自定义波段式** / 灰度单波段
- 自定义表达式：`b1..bN` 对应波段 1..N，支持 `sqrt log exp abs clip where nan_to_num` 与四则运算，例：
  - NDVI = `(b4-b3)/(b4+b3)`　NDWI = `(b2-b4)/(b2+b4)`　NDBI = `(b5-b4)/(b5+b4)`
  - 三个预设按钮一键填入；非法字符/波段名在服务端校验并回滚报错
  - 应用后自动把波段组合切到「自定义波段式」

**C. 几何变换**（生成**新文件**并打开；原文件与原标注不动，现有标注自动换算）
- ✂ 裁剪到当前选区（取外接矩形，任意选框/套索/魔棒选区均可）
- ↻ 顺时针 90° · ↺ 逆时针 90° · ⇄ 180° · ⇋ 水平翻转 · ⇅ 垂直翻转
- 派生文件命名：`原名_crop.tif` / `_rot90.tif` …（重名自动加序号），同时生成配套 `.label.npy` 与 `.parcels.geojson`

### 1.6 自动保存与撤销
- **矢量**（田块/文本/类别改动）：停止编辑 0.9 秒后自动写 GeoJSON；**标签图**：1.2 秒后写 npy（原子写：先 .tmp 再替换）；涂抹的每笔提交本身即触发；
- 状态栏 **「● 已保存 时:分:秒」** 实时反馈；可取消勾选「自动保存」改手动 `Ctrl+S`；空闲时每 20 秒兜底检查；
- **统一历史栈**：多边形、涂抹、文本、删除共用 `Ctrl+Z / Ctrl+Y`，涂抹采用分块补丁撤销（内存占用恒定）；栈深 80–300 步。

### 1.7 导出
- **⤓ GeoJSON**：浏览器直接下载；
- **⤓ 标签TIFF**：与影像同 CRS/Transform 的 uint8 单波段 GeoTIFF（deflate）；
- **⤓ 统计**：各类别像素数 / 占比 / 面积(ha) 的 CSV（UTF-8-BOM，Excel 直开）；
- **田块→标签图**（侧栏按钮）：把所有矢量田块按其类别一次性栅格化进标签图。

### 1.8 多人实时协作
同一地址（局域网 IP）在多台电脑打开即自动组队，无需注册账号：

| 能力 | 说明 |
|---|---|
| **协作身份** | 首次进入弹出「起个名字」对话框（昵称 + 8 色可选），存浏览器 localStorage；点顶部头像栏随时改名换色 |
| **在线头像栏** | 工具栏右侧彩色头像 + 在线人数，绿点 = 在线；25 秒无心跳自动离线并广播 leave |
| **远程光标** | 画布上实时显示其他成员的光标（彩色圆环 + 名字标签），随平移缩放同步换算 |
| **事件浮层** | 画布右上角滚动提示：加入 / 离开 / 保存 / 涂抹 / 清空 / 栅格化 / 类别变更（4.8 秒自动淡出） |
| **矢量增量合并** | 本地保存只发**改动的要素**（upsert + remove 按 `p:ID`/`t:ID` 键合并），服务端按要素级 last-writer-wins，互不覆盖；带 `owner`（创建者）/`editor`（最后编辑者）溯源字段；远端保存事件触发自动拉取刷新（`rev` 修订号比对，本地有未保存改动时延迟到保存后再合并） |
| **按人撤销** | 涂抹/清空/栅格化每笔记录归属；`Ctrl+Z` 只撤销**自己**的最近一笔（栈中摘除 + 区域裁剪重放，不破坏他人后画的内容）；无可撤销时提示 |
| **按人统计** | `GET /maskval?client=` 返回每人的笔画数 / 净像素 / 分类别明细 |
| **标签图同步** | 远端涂抹/撤销/清空事件 → 本端节流刷新叠加层与统计 |
| **影像切换广播** | 他人打开新影像 / 几何变换时，本端收到提示并自动刷新页面 |

**协作注意**：同一浏览器的多个标签页共享同一身份（localStorage 同源）；不同电脑/不同浏览器即为不同用户。矢量并发编辑同一要素时**后保存者生效**；建议同一影像由一人主导圈画、其他人分工涂抹。

## 二、安装与启动

### 方式 A：便携版（推荐）
解压 `FieldLabel_v1.0_portable.zip` → 双击 `启动工具.bat`。**目标电脑无需 Python/GDAL/任何依赖**。

### 方式 B：源码
```powershell
cd fieldlabel
pip install -r requirements.txt     # rasterio + Pillow + numpy
python annotate.py                  # 页面里再选影像
python annotate.py D:\data\img.tif  # 直接预载影像
python annotate.py D:\data          # 预载目录里第一张
```
也可直接双击 `启动.bat`（缺依赖会自动安装）。

### 方式 C：局域网多人协作
默认监听 `0.0.0.0`，启动时终端打印 `http://192.168.x.x:8765/`，同一局域网其他电脑浏览器打开即可。进入时各自起个名字，即组成协作小组：**在线头像、远程光标、事件提示、矢量增量合并、标签图实时同步、涂抹按人撤销**全自动（详见 [1.8 多人实时协作](#18-多人实时协作)）。只想本机用加 `--local-only`（此时仍可开多个浏览器窗口协作，只要走同一地址）。

### 命令行参数
| 参数 | 作用 | 默认 |
|---|---|---|
| `path`（位置参数） | 影像文件或目录，可省略 | 空（页面里选） |
| `--port` | 监听端口 | `8765` |
| `--host` | 监听地址 | `0.0.0.0` |
| `--local-only` | 仅本机（127.0.0.1） | 关 |
| `--no-browser` | 不自动弹浏览器 | 关 |

## 五、典型工作流教程

### 场景 A：圈出一块块农田（矢量）
1. `📂 打开文件` 选影像 → 按 `P`；
2. 沿田埂逐点单击，回到起点/右键闭合；
3. （可选）`V` 选中后拖顶点精修，右侧属性卡改类别；
4. 状态栏出现「已保存」即完成——不用手动存。

### 场景 B：魔棒一键标同质地块
1. 按 `W`，右侧面板把**容差**调到 30 左右；
2. 在目标地块上单击 → 蚂蚁线自动包住整块（太小调大容差，太大调小）；
3. 点 **「转为田块」**（要改边界）或 **「涂进当前类别」**（直接进标签图）；
4. 换类别（`2`、`3`…）继续点下一块。

### 场景 C：做语义分割训练标签
1. 选类别（如「耕地」）→ 按 `B` 涂抹，或用魔棒+「涂进当前类别」；
2. 涂抹结果实时以半透明色叠在影像上；涂错了按 `E` 擦，或 `Ctrl+Z`；
3. 侧栏「统计」看各类像素量；需要时点「田块→标签图」把矢量也栅格化进去；
4. 训练时直接读 `<影像名>.label.npy`（uint8，0=背景）——与 `outputs/label_*.npy` 完全同构。

### 场景 D：先裁剪/旋转再标
1. 按 `R` 框选要的范围 → 打开 🎛 面板 → 「✂ 裁剪到当前选区」；
2. 确认对话框会告诉你生成什么文件；几十秒内切换到新文件；
3. 若之前已有标注，**坐标自动换算**到新文件（原图标注不动）；
4. 后续直接在派生文件上继续标，导出同样格式。

### 场景 E：调色/多光谱辅助判读
1. `I` 打开面板：勾「光平衡」校正色偏 → 拉「对比度/饱和度」让田块边界更清楚；
2. 波段组合切 **NDWI** 看水体（蓝色调）、**NDVI** 看长势、或输入自定义波段式；
3. 看清之后照常标注——所有调整只影响显示，**导出的标签与原数据完全一致**；
4. 用 `T` 在图上打文字备注（如「地块 A · 7月拔节期」）。

## 六、输出文件与数据格式规范

结果全部写在**被标注影像的同目录**，与影像同名。

### 6.1 `<影像名>.parcels.geojson`（矢量 + 文本）
```jsonc
{
  "type": "FeatureCollection",
  "features": [
    {                                  // ① 田块（Polygon）
      "type": "Feature",
      "properties": {
        "id": 1,                       // 田块编号（从 1 递增）
        "cls": 4,                      // 类别 ID（对应类别表）
        "class_name": "水体",
        "area_ha": 12.3456,            // 面积（公顷，地理坐标按当地纬度换算）
        "image_px": [[x,y], ...]       // 图像像素坐标（1 位小数，回读首选，无损）
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[lon,lat], ...]]  // 影像 CRS 下的闭合环（首尾重复）
      }
    },
    {                                  // ② 文本标注（Point）
      "type": "Feature",
      "properties": {
        "type": "text", "id": 1, "cls": 1, "class_name": "耕地",
        "text": "地块A·7月拔节期",
        "image_px": [x, y]
      },
      "geometry": {"type": "Point", "coordinates": [lon, lat]}
    }
  ]
}
```
- 回读优先用 `image_px`（像素坐标无损），缺失时用 `geometry` 经纬度经仿射逆变换还原；
- **v1 老文件**没有 `cls` 字段 → 页面自动归为类别 1，不影响打开；
- **协作溯源字段**（多人模式下由服务端盖章）：`owner`（创建者昵称）、`editor`（最后编辑者昵称）、`mtime`（Unix 秒）——单机模式不产生这三个字段，不影响任何读取方。

### 6.2 `<影像名>.label.npy`（语义标签图）
- `numpy.load` 直接读：`uint8`，shape = `(影像高, 影像宽)`；
- 取值：`0` = 背景，`1..N` = 类别 ID；
- 与项目里 `outputs/label_Shouyang.npy`、`label_Zhangzi.npy` **格式完全一致**，训练代码零改动；
- 自动保存，编辑后约 1 秒落盘；文件大小 ≈ 宽×高 字节（8350×6352 ≈ 50 MB）。

### 6.3 按需导出
| 文件 | 内容 |
|---|---|
| `<影像名>_label.tif` | uint8 单波段 GeoTIFF，同 CRS/Transform，deflate 压缩 |
| `<影像名>_label_stats.csv` | `class_id,class_name,pixels,ratio,area_ha`（UTF-8-BOM） |
| GeoJSON（⤓ 按钮） | 浏览器直接下载，与 6.1 相同 |

### 6.4 几何变换派生文件
`<影像名>_crop / _rot90 / _rot90ccw / _rot180 / _fliph / _flipv` 系列：
- 派生 GeoTIFF（正确的新仿射矩阵，地理坐标连续）
- 配套 `.label.npy`（掩膜同步裁剪/旋转）与 `.parcels.geojson`（标注已换算）
- 重名自动追加 `_1`、`_2`…；**原文件永不修改**

## 十、HTTP API 附录

服务仅监听 HTTP，JSON 进出；错误一律 `500 {"error": "..."}`。供二次开发/自动化调用。

### GET
| 路径 | 参数 | 返回 |
|---|---|---|
| `/` | — | 页面 HTML |
| `/info` | — | `{scene?, classes, adj, labels_path, mask_path, mask, last_dir, recent}` |
| `/browse` | `path`（空=列盘符）, `all=1`（显示全部文件） | `{path, parent, dirs[], files[], recent, home}` |
| `/tile` | `z,x,y`（可为负、浮点缩放层级）, `combo`, `band` | PNG 瓦片 |
| `/overlay` | `z,x,y`, `hide="1,3"`（隐藏的类别） | PNG 半透明类别图层 |
| `/parcels` | — | GeoJSON FeatureCollection（田块+文本），附 `rev` 修订号字段 |
| `/maskinfo` | — | `{mask:{counts:{cls:px}, strokes, can_undo, can_redo, mask_rev, last_saved, ...}}` |
| `/maskval` | `x,y` 取像素类别（吸管）；`client=ID` 按人统计 | `{cls}` 或 `{stat:{name,n,px,by_cls}, mask_rev}` |
| `/users` | `since=seq`（增量事件起点） | `{users:[{id,name,color,last,cursor}], events:[{seq,type,client,name,data}], seq, rev}` |
| `/classes` | — | `{classes:[...]}` |

### POST（body 为 JSON，均自动附带 `client`/`name` 身份字段）
| 路径 | body | 说明 |
|---|---|---|
| `/open` | `{path}` | 打开影像，返回 `{info, classes, mask, files}`；广播 `open` 事件 |
| `/save` | 旧式：`{features:[...]}` 整体替换；**协作式**：`{mode:"merge", upsert:[...], remove:["p:2","t:1"], client, name}` | 按键增量合并（原子写），返回 `{ok, path, rev, count}`；广播 `save` 事件 |
| `/classes` | `{classes:[{id,name,color}]}` | 保存类别表并写配置；广播 `classes` 事件 |
| `/users` | `{client, name, color?, cursor?[x,y], since?, action?:\"leave\"}` | 注册/心跳/光标上报；新人广播 `join`；`action:\"leave\"` 主动离场广播 `leave`；返回在线列表与增量事件 |
| `/stroke` | `{points:[[x,y]..], size, cls, erase, client, name}` | 提交一笔涂抹/擦除（记录归属）；广播 `stroke` 事件含 `mask_rev` |
| `/mask_undo` `/mask_redo` | `{client, name}` | 标签图撤销/重做——**给 client 时只动自己的笔画**（栈中摘除 + 区域重放） |
| `/mask_clear` | `{cls}` 或 `{cls:-1}` 全清，可带 `client` | 清除某类/全部涂抹；广播 `clear` 事件 |
| `/bake` | `{features, cls, client?}` | 矢量多边形栅格化进标签图；广播 `bake` 事件 |
| `/wand` | `{x, y, tol(1-100), win?}` | 魔棒：返回 `{polygon:[[x,y]..], area_px, n, partial}` |
| `/adj` | `{adj:{brightness,contrast,saturation,gamma,sharpen,wb,lo,hi,expr}}` | 更新显示调整/表达式（服务端校验） |
| `/derive` | `{kind:"crop"\|"rot90"\|"rot90ccw"\|"rot180"\|"fliph"\|"flipv", x,y,w,h(crop)}` | 几何变换生成新文件并切换，返回新 `{info, mask}`；广播 `derive` 事件 |
| `/export_tif` `/export_csv` | `{path?}` | 导出标签 TIFF / 统计 CSV，返回绝对路径 |
| `/flush` | `{}` | 立即落盘标签图 |
| `/shutdown` | `{}` | 优雅退出服务 |

**事件类型（`events[].type`）**：`join` / `leave` / `save`（含 `rev`）/ `stroke` / `undo` / `redo` / `clear` / `bake` / `classes` / `open` / `derive`。客户端用 `since=seq` 增量拉取，忽略自己 `client` 的事件。

## 十一、常见问题与排查

**启动 / 端口**
- **提示「端口 8765 不可用」**：已有实例在跑（可能还有旧版工具占着同一端口）。`Get-NetTCPConnection -LocalPort 8765 -State Listen` 查占用者，然后 `--port 8766` 换端口，或关掉旧进程。
- **浏览器没自动弹出**：手动访问 `http://127.0.0.1:8765/`（换过端口就改端口号）。
- **局域网别人连不上**（按序排查，前两步解决 99%）：
  1. **服务是否绑对地址**：启动日志必须显示 `LAN: http://...`；带 `--local-only` 启动只有本机能用（去掉即可，服务默认绑定 `0.0.0.0`）。便携版用 `启动工具.bat` 启动会**自动完成防火墙放行**（首次弹 UAC 点"是"）；源码/手动启动请放行 Python 或 `FieldLabel.exe` 的入站，或临时：
     ```powershell
     # 管理员 PowerShell，按实际路径改
     New-NetFirewallRule -DisplayName "FieldLabel (LAN)" -Direction Inbound -Program "X:\...\FieldLabel.exe" -Action Allow -Profile Any -Enabled True
     ```
  2. **地址与端口**：对方必须访问 `http://本机IP:端口/`（带端口号，默认 `8765`；换过端口要跟着换）。
  3. **网络层**：两台设备在同一网段/SSID；对端 `ping 本机IP` 通不通——不通多为路由器开了 **AP 防隔离**（禁止设备互访，需在路由管理页关闭）或访客网络隔离。
  4. 杀毒/安全软件的"局域网防护"可能另行拦截，临时退出对比验证。

**性能**
- **打开大影像慢**：首次 1–3 秒拉伸统计属正常；8350×6352 全部用瓦片缓存，之后丝滑。
- **魔棒慢**：默认窗口 1200px，区域触边自动扩到 2400px 重算；大区域 1–3 秒正常，超大容差会标记 partial。
- **旋转/翻转要等**：需要读写整幅数据，6 波段大图十几到几十秒，状态栏显示「几何变换中…」（写入已用 ZLEVEL=1 加速）。
- **标签文件大**：`label.npy` ≈ 宽×高字节，属设计如此。

**数据 / 显示**
- **标签没显示**：右上「标签图层」勾上；或某类被 ● 隐藏了。
- **调整后影像没变**：波段组合切回「真彩色」看；自定义表达式需切到「自定义波段式」。
- **类别变回默认**：`annotator_config.json` 被删或目录无写权限。
- **恢复默认显示调整**：🎛 面板里点「↺ 重置显示调整」。
- **v1 的老标注能读吗**：能，`cls` 缺失自动归为类别 1；新保存时会补齐全部字段。

**打包版**
- SmartScreen 拦截 → 「更多信息 → 仍要运行」；
- 缺 DLL → 装 VC++ 2015-2022 x64 运行库；
- 病毒软件误报（PyInstaller 常见）→ 加白名单；
- `annotator_config.json` 写不进 → 程序目录没有写权限，换到普通目录。

**崩溃/并发**
- 服务对 rasterio 数据集句柄做了全链路加锁，瓦片/魔棒/裁剪旋转并发安全；矢量按要素增量合并（见 1.8），标签图为**按人归属的共享单文件**（同一标签图多人同时涂抹时按笔提交、最后落盘者生效，建议涂抹由一人主导或分工不同类别）。
- 万一服务端异常退出：命令行窗口里会有 Python Traceback，重启即可——已保存的数据都在磁盘上，最多丢最后 1 秒内的编辑。
